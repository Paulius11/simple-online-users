# Simple Online Users

A lightweight Odoo 17 module that displays the count of currently online users in the systray.

## Features

- Real-time online user count display in systray
- Clean integration with Odoo interface
- Uses native `bus.presence` system
- Configurable visibility permissions
- Popup showing detailed user list with status
- No custom models or complex setup required

## Installation

1. Copy the module to your Odoo addons directory
2. Update the addons list in Odoo
3. Install the "Simple Online Users" module
4. Configure visibility permissions in Settings > General Settings > Online Users

## Requirements

- Odoo 17.0
- Dependencies: `base`, `web`, `bus`
